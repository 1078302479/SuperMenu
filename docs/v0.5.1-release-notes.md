# v0.5.1

- 修复 Finder 菜单动作点击无反应，以及图片转换在选中项变化后丢失目标。
- 重新设计通用设置：等高卡片、自适应高度、固定底部检查栏和紧凑更新区域；权限就绪统一绿色，需处理采用橙色。
- 权限探测加入超时与无法确认状态，显示最近检查时间。
- 新增强制发布前检查和统一发布入口；README 更新实际功能截图。

验证：完整自动回归、临时 APFS 跨卷、发行资源及签名、升级包预检、安装脚本替换/失败恢复；用户确认 Shift 右键可用，Finder 重启首次菜单实测通过。最终以本次 release-preflight 报告为准。

限制：临时签名覆盖升级可能需要重新添加辅助功能授权；没有 Apple 公证。完整应用内升级确认至重启、多窗口实际动作、重新登录首次右键、OneDrive 仍未全部实机验收。中键和多选自动点击按用户要求跳过。后台回归不代表这些交互通过。

同版本修订：重新设计永久删除确认框，采用紧凑布局及明确的不可撤销提示，默认取消；回车不会触发删除。版本保持 0.5.1，源码修订以 main 最新提交为准，原版本标签保留。
