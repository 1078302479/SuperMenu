## 第二阶段：云盘触发可行性

- 修饰键右键、中键：公开鼠标事件监听可用，但不能通过只读全局监视器阻止原始右键。完整替代菜单需事件截获与用户明确授予的辅助功能权限，并可靠读取鼠标所在访达窗口上下文；不能误用另一个窗口的选中项。
- 三指触发：Apple 公开全局事件监听不提供原始触摸事件，不能把 NSView 内部触摸手势当成访达全局手势。禁止启用没有对应实现的开关；是否采用私有接口需另行评估系统兼容性。
- 云目录需覆盖iCloud、OneDrive、离线占位文件、选中项与空白区域。不得为了测试改变用户云文件内容。
- 参考：Apple NSEvent.addGlobalMonitorForEvents 文档、TN3212；首次实机验证前保留未完成状态。

## 后续顺序

1. 应用内下载进度、哈希校验、安装引导/替换及重启，保留配置和自定义数据。
2. 15种格式逐个编辑器兼容性检查；对应软件未安装的标为未测而非通过。
3. 首次右键、覆盖升级、重新登录、新窗口、外置盘回归；实际显示为判据。
4. 打包脚本统一版本/构建号与Apache-2.0、NOTICE，模板/图标完整性和干净源码构建检查。

本轮仅本地开发验收，不提交推送或发布 Release，除非用户另行授权。

## 本轮实现与验证记录

- 用户已明确选择：先做修饰键右键和鼠标中键，三指暂不开放。两个入口默认关闭，主动开启时才申请辅助功能权限；仅在识别到鼠标下的 iCloud / OneDrive 访达目录时接管事件。无法可靠识别时保留系统鼠标行为。
- 访达扩展和云盘入口共用菜单构造、名称、排序、图标及请求处理。目录和选中项随当次操作传递。
- 更新模块新增下载进度、取消、SHA-256 校验、压缩包路径检查、应用签名/版本/标识及模板检查、同目录替换和重启；失败保留手动下载入口。设置及自定义模板目录不随应用替换。
- v0.5.0（44）本地发行构建通过。DMG 创建及校验通过，ZIP 已生成；两个包均未上传。发行检查确认主程序与扩展版本一致、模板及参考图标字节完整、Apache-2.0 和 NOTICE 入包。
- 后台测试通过：15种格式创建、图标与图片转换、菜单改名及配置、云盘路径筛选、更新附件/哈希解析、真实发行 ZIP 解压及验证、错误版本拒绝。完整日志：`.build/v050-tests.log`；新包及跨卷复测：`.build/v050-final-tests.log`。
