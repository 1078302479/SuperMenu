# 增强右键与原版差异核对

核对对象：用户本次两张 Finder 菜单截图、本地源码及 v0.3.8 本地验收包。未重新逐个操作原版全部功能，因此下列结论区分已验证和待实机核对；不能据此宣称已达到完整 1:1。

## 本轮修正与验证

| 项目 | 修正及证据 |
| --- | --- |
| 新建文件 | 换用原版文档加号图标，替换原有青色线框替代图标 |
| 拷贝路径 | 换用原版蓝绿横向链条，替换斜向系统链条 |
| 移动文件到、复制文件到 | 分别补入原版箭头资源 moveFilesTo、copyFilesTo，替换文件夹和叠纸图标 |
| 其他工具栏、菜单、应用图标 | 本地参考图标共 75 张；逐字节验证在主程序和 Finder 扩展中均存在且一致，本地与分发模式验收包四处均无缺失 |
| 文件夹预设 | 保留本地原版预设资源；后台测试验证预设加载、排序、改名、启用和移除自定义图标 |
| 图片转换 | 正常菜单入口改为直接输出至原文件同目录；成功不创建进度或完成窗口。失败仍报告错误 |
| 转换重名及原图 | 回归验证原图字节不变，第二次输出自动编号；PNG/JPG/WebP/HEIC/ICNS 及图标集回归通过 |

截图中原版和增强右键扩展同时启用，形成两组重复菜单。上方原版图标和下方增强右键图标需要分开比较，不能把两组重复算成单个扩展的排序错误。

## 仍存在的明确差异

| 项目 | 当前状态 | 影响 |
| --- | --- | --- |
| 云盘触发方式 | 修饰键右键、中键、触控板三指三项仍禁用，源码明确标为未实现 | 与原版功能不一致 |
| 分发模式内置新建格式 | 自带 TXT、Markdown、RTF、XML、Word、Excel、PPT 共 7 种；WPS 三种、Pages、Numbers、Keynote、AI、PSD 未随分发模式打包 | 开发包可读取本机参考模板，不能代替下载包验证；其余格式需导入有效模板 |
| 图标资源随源码分发 | 本轮原版 PNG 仅在本地验收资源目录，Git 忽略它们 | 本地包图标恢复，不等于 GitHub 干净检出构建已包含相同资源；发布前必须解决并单独验包 |
| 设置页面视觉 | 仍使用当前浅色 SwiftUI 页面，标题、间距、表格边框及控件风格与原版截图不同 | 图标修复不代表设置页面像素级一致 |
| 文件（夹）图标右键子菜单 | 按此前用户要求从右键移除，设置页保留应用及恢复入口 | 属于用户要求的差异，本轮不擅自加回 |
| 第三方联动 | 部分操作只打开 iShot、DiskMap、FastZip 继续处理，并非完整调用对应操作 | 按此前要求暂缓第三方联动，不计为本轮已完成 |

## 尚未完成原版实机逐项对照的内容

- 转换后原版的准确文件命名、同名处理、透明背景、色彩配置及元数据保留。当前仅确认按用户描述同目录静默输出，以及本项目回归行为。
- 大批量和超大图片转换耗时、失败反馈与原版的差异。
- 所有菜单在空白区域、单文件、多文件、文件夹、云盘各场景的显示条件和默认顺序。
- 安装至实际应用程序目录后的首次 Finder 菜单出现时机、扩展启用检测及系统设置跳转。当前后台测试不能替代首次安装实机验收。
- 不同 macOS 版本及 Retina 缩放下图标最终视觉效果。本轮验证了资源完整性，未把后台资源测试等同于前台逐项截图验收。
