## 用户复测失败与权限证据修正

用户反馈“刚试了不行”。读取配置发现修饰键右键、中键均关闭，已通过设置界面开启，写入配置确认均为 true。随后读取实际应用窗口，仍显示“需要辅助功能授权，请在下方权限区设置”和重新添加授权引导，尚未就绪。

从命令行直接启动的权限探测返回 true，与应用窗口状态矛盾。因此此前命令行 true 不能证明主应用具备鼠标监听权限，不可将本机权限连续保留视为通过。已要求用户按应用引导重新添加当前应用并重启复测；未擅自修改 TCC 数据库或重置其他权限。实体云盘验收仍为失败待修复/复测。

## 重新授权后用户验收

用户完成移除旧授权、重新添加当前应用并反馈“好了，右键我测试过了”，进一步确认范围为 **Shift 右键**。本轮据此将 Shift 右键入口标为用户验收通过；没有扩展为中键、多窗口、文件/多选操作及重新登录均通过。
