# SuperMenu 浅色设计方案

本轮按 frontend-design 技能先确定视觉系统，再替换整个样式层，避免历次颜色覆盖互相干扰。

## 视觉系统

- 纸白 #FFFFFF：主内容区。
- 雾灰 #F5F6F8：侧栏、表头与静态底色。
- 细线灰 #E6E8EE：分区和表格边界。
- 石墨 #282C37：标题与重要文字。
- 中灰 #747B8C：功能说明与选项。
- 鸢尾蓝 #6268CE：选中项、主要操作、鼠标右键标记。

字体使用 macOS 系统字体与苹方：22px 页标题、17px 品牌名、12–13px 内容、11px 辅助文字。正文和标签左对齐；复选框与格式图标列居中。

## 布局

保留竞品易理解的设置结构，使用更轻的视觉重量。品牌由居中大图标改为紧凑的横向标识；标题下补充一句任务说明；内容表格保持单一工作区，预览按需打开。

```text
┌────────────┬─────────────────────────────────┐
│ 窗口控制    │ 功能标题                         │
│ 图标 品牌   │ 当前页面的简短操作说明             │
│            ├─────────────────────────────────┤
│ 功能分区    │ 表头                            │
│ 选中的功能  │ 可编辑表格、启用项、选项           │
│ 其他功能    │                                 │
│            │ 添加 / 移除               重置   │
│            │ 显示偏好                         │
│ 帮助       ├─────────────────────────────────┤
│            │ 本次预览状态                     │
└────────────┴─────────────────────────────────┘
```

## 图标

应用图标表现完整鼠标轮廓，右键独立着色，滚轮居中；右上短线表示按下动作，右下小菜单表示结果。保留轮廓与右键色块在小尺寸下的辨识度。SVG 为可继续调整的原创矢量源文件，不依赖外部素材。

## 自检与交付边界

已避免将所有内容统一染成灰蓝色；正文与辅助说明区分，彩色只用于交互和图标中的右键。没有引入卡片仪表盘、宣传标题、装饰动画。网页复选框与输入框保留键盘操作和可见焦点；窄屏收起侧栏文字。七个页面和弹窗渲染路径检查通过。尚未完成实际浏览器截图与视觉验收。

## 格式图标保留

用户以新建文件列表截图明确要求保留格式图标的辨识度：Word 蓝色 W、Excel 绿色 X、PPT 橙色 P；WPS 各格式、Pages、Numbers、Keynote、AI、PSD 保留各自色彩与形状语言；TXT 保留文稿与笔、XML 保留文稿与地球意象。界面背景及选中态可以调整，不将格式图标整体染成灰色。当前设计稿使用自绘 SVG 近似表达，非从截图提取的原始应用图标；原生实现阶段优先调用系统提供的文件类型图标。

## 原版图标资源替换

依据用户最新反馈，当前设计稿已用本地 iRightMouse 包内的原始图片替换近似绘制图标：侧栏、文件格式、工具箱操作、终端/编辑器入口、文件夹预设。工具箱 61 项均已接入原始资源；当前页面渲染涉及 82 个不同原始图标文件，路径存在性检查通过。来源与原名称映射见 `reference-icons/来源说明.md` 和 `index.json`。

延续浅色窗口与我们自己的右键应用图标；复选框恢复系统蓝色。此前“全部图标自绘”的说明仅适用于早先版本，已由本节更新。

## 工具箱底部完整对齐

根据用户指出的遗漏，补齐独立的底部操作与菜单设置区：左侧“新建进入 App / 删除”，右侧“申请其他功能 / 重置”；下方“显示图标”和三项菜单合并选项。桌面下按原版的两列形式排布，窄屏改为单列。默认显示图标，三项合并选项默认不勾选，每项有独立帮助按钮。底部使用不可收缩区域，只有上方表格滚动。

交互：仅自定义 App 可删除，内置项通过开关停用；重置显示确认面板并恢复初始配置；需求反馈可以暂存草稿但不发送；显示图标实际切换列表图标可见性。菜单合并选项保存本次预览状态，尚未连接系统 Finder。

### 底部区域裁切修复

用户截图暴露了实际布局问题：外层 Grid 子项 main 的自动最小高度被完整表格内容撑大，App 的 overflow 裁切掉底部区域。已将 Grid 行设为 minmax(0,1fr)，main/content 明确 min-height:0 并约束 overflow；表格 flex:1 1 0 且独立 overflow:auto；标题、筛选、底部按钮及偏好设置不收缩。去除整个窗口的强制最小高度，避免较矮视口下超出屏幕。此前控件渲染检查不能代替浏览器布局验收。本轮无法通过电脑工具观察 Codex 内嵌预览，仍需实际页面验证。

## 应用标识定稿方向更新

参考原版“浅色圆角底座 + 彩色圆形标识”的构成，改为青蓝至靛蓝圆形底色，内部使用白色鼠标轮廓、独立高亮的右键、点击短线与弹出菜单。保持 SuperMenu 的右键语义，不使用原版 R 字标。512px 可缩放 SVG 源文件与左上角嵌入版本已同步，其他功能图标保持不变。
