# 本地设计参考资源

来源：本机 `/Applications/iRightMouse.app/Contents/Resources/Assets.car`。
用途：在本地交互设计稿和开发包中保留原版图标展示效果。开发包使用新建文件及格式图标，以及已接入的文件操作与工具箱图标。
提取方式：assetutil 读取命名清单；AppKit Bundle.image(forResource:) 读取图像并导出 PNG。未修改原应用。
映射：index.json 记录原资源名与 PNG 文件路径。

包含侧栏、格式、文件操作、第三方应用与文件夹预设图标；不替换 SuperMenu 自己的应用标识。导出的图片保留原颜色和形状，显示尺寸适配当前设计稿。此来源记录不表示图标为 SuperMenu 原创或已取得再分发授权。

Git 仅跟踪映射和来源记录。PNG 保存在本机，缺少这些文件时设计稿显示占位图标，开发包显示系统图标。
